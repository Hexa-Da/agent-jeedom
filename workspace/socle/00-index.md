# Socle de connaissances Jeedom (v1)

Sources : documentation officielle Jeedom (cible terrain : Atlas, core **4.6.1** ; docs 4.4 à 4.6, boxes Atlas/Smart/Luna) résumée en français. Les noms de menus peuvent légèrement varier selon la version du core : en cas de doute, demander une capture d'écran.

| Fiche | Quand la lire |
|---|---|
| `atlas.md` | Première connexion, accès à la box, restauration système, protocoles de l'Atlas |
| `interface-menus.md` | « Où se trouve… ? », structure des menus, Dashboard, Synthèse |
| `objets-equipements-commandes.md` | Comprendre objets, équipements, commandes, plugins, tuiles absentes du Dashboard |
| `scenarios.md` | Créer ou comprendre un scénario, déclencheurs, blocs, tags, lever/coucher du soleil |
| `sauvegarde-restauration.md` | Sauvegarder avant un changement, restaurer, sauvegarde cloud |
| `mise-a-jour.md` | Mettre à jour le core ou les plugins |
| `depannage-de-base.md` | Un scénario ne se lance pas, un équipement n'apparaît pas, où regarder les logs |
| `glossaire.md` | Expliquer un terme en mots simples |

Limites de ce socle : il ne détaille pas les plugins individuels (Zigbee, Z-Wave, etc.) ni chaque équipement. Pour ces sujets, demander une capture de la page du plugin ou de l'équipement.
